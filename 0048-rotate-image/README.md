# 0048 - Rotate Image

## Problem

You are given an `n x n` 2D matrix representing an image. Rotate the image by 90 degrees clockwise.

The rotation must be done **in-place**, which means the input matrix must be modified directly without creating another matrix.

## Example

Input:

```text
[[1,2,3],
 [4,5,6],
 [7,8,9]]
