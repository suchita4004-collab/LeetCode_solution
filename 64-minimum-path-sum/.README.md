# 64 - Minimum Path Sum

## Problem

Given a `m x n` grid filled with non-negative numbers, find a path from the **top-left corner** to the **bottom-right corner** such that the sum of all numbers along the path is minimum.

You can only move:

- **Right**
- **Down**

The goal is to return the **minimum possible path sum**.

---

## Examples

### Example 1

**Input:**
```text
grid = [[1,3,1],
        [1,5,1],
        [4,2,1]]
```

**Output:**
```text
7
```

**Explanation:**

The minimum path is:

```text
1 → 3 → 1 → 1 → 1
```

Sum:

```text
1 + 3 + 1 + 1 + 1 = 7
```

---

### Example 2

**Input:**
```text
grid = [[1,2,3],
        [4,5,6]]
```

**Output:**
```text
12
```

**Explanation:**

The minimum path is:

```text
1 → 2 → 3 → 6
```

Sum:

```text
1 + 2 + 3 + 6 = 12
```

---

## Approach

We use **Dynamic Programming (DP)**.

For every cell, we calculate the minimum sum required to reach that cell.

For a cell `grid[i][j]`, we can reach it from:

1. The cell above: `grid[i-1][j]`
2. The cell on the left: `grid[i][j-1]`

Therefore:

```text
Minimum Path Sum =
Current Value + min(Top, Left)
```

We store the calculated minimum sum directly inside the grid.

---

## Algorithm

1. Find the number of rows `m` and columns `n`.
2. Update the first row because we can only move from left to right.
3. Update the first column because we can only move from top to bottom.
4. For every remaining cell:
   - Take the minimum value from the top and left cells.
   - Add it to the current cell.
5. The bottom-right cell contains the minimum path sum.
6. Return `grid[m-1][n-1]`.

## Solution

```python
class Solution:
    def minPathSum(self, grid):
        m = len(grid)
        n = len(grid[0])

        # Update first row
        for j in range(1, n):
            grid[0][j] += grid[0][j - 1]

        # Update first column
        for i in range(1, m):
            grid[i][0] += grid[i - 1][0]

        # Calculate minimum path sum
        for i in range(1, m):
            for j in range(1, n):
                grid[i][j] += min(grid[i - 1][j], grid[i][j - 1])

        return grid[m - 1][n - 1]
```

---

## How the Code Works

### 1. Find grid dimensions

```python
m = len(grid)
n = len(grid[0])
```

This gives the number of rows and columns.

### 2. Calculate the first row

```python
for j in range(1, n):
    grid[0][j] += grid[0][j - 1]
```

There is only one possible way to reach cells in the first row — moving from the left.

### 3. Calculate the first column

```python
for i in range(1, m):
    grid[i][0] += grid[i - 1][0]
```

There is only one possible way to reach cells in the first column — moving from above.

### 4. Calculate remaining cells

```python
grid[i][j] += min(grid[i - 1][j], grid[i][j - 1])
```

We choose the smaller path from the top or left and add the current cell's value.

### 5. Return the answer

```python
return grid[m - 1][n - 1]
```

The bottom-right cell contains the minimum path sum.

## Complexity Analysis

### Time Complexity

```text
O(m × n)
```

We visit every cell once.

### Space Complexity

```text
O(1)
```

We modify the input grid directly and do not use an additional DP array.

---

## Key Concept

The main concept used in this problem is:

**Dynamic Programming**

At each cell:

```text
dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])
```

This avoids calculating the same paths repeatedly.

## Constraints

- `1 <= m, n <= 200`
- `0 <= grid[i][j] <= 200`
- `m == grid.length`
- `n == grid[i].length`
